# Зерно — интернет-магазин свежеобжаренного кофе

## Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

Сайт интернет-магазина небольшой обжарочной «Зерно»: кофе в зёрнах, всё для заваривания и аксессуары. В проекте есть главная страница, каталог с фильтром, страница товара, оформление заказа и страница контактов. Интерфейс сделан на Bootstrap, свои стили — в файле `css/custom.css`.

## Используемый фреймворк

Bootstrap 5.3.8.

## Способ подключения Bootstrap

В проекте Bootstrap подключён **локально**, без CDN. Файлы фреймворка размещены в папке `vendor/bootstrap/`.

Используются:

- `vendor/bootstrap/css/bootstrap.min.css` — стили Bootstrap, подключаются в `<head>`;
- `vendor/bootstrap/js/bootstrap.bundle.min.js` — Bootstrap JS Bundle, подключается в конце `<body>`. Нужен для мобильного меню, выпадающего списка, карусели, модальных окон, аккордеона, вкладок и уведомлений.

Файл `css/custom.css` подключается **после** Bootstrap, чтобы свои стили могли переопределять стили фреймворка:

```html
<link rel="stylesheet" href="vendor/bootstrap/css/bootstrap.min.css">
<link rel="stylesheet" href="css/custom.css">
```

## Bootstrap-сетка

- `container`, `row`, `col-*`, `col-12`;
- адаптивные колонки `col-sm-*`, `col-md-*`, `col-lg-*`;
- смещения `offset-md-*`, `offset-lg-*` (карточки в блоке «От зерна до чашки»);
- вложенная сетка: `row` внутри колонки (фотографии на странице товара);
- отступы между колонками `g-3`, `g-4`, адаптивные `g-lg-5` и `gx-lg-5`, а также `gy-4`.

## Реализованные Bootstrap-компоненты

- `navbar` — меню на всех страницах, на телефоне сворачивается в кнопку;
- `dropdown` — выпадающее меню «Каталог»;
- `carousel` — hero-блок на главной;
- `card` — карточки товаров, преимуществ, контактов, итога заказа;
- `btn` — кнопки `btn-primary`, `btn-outline-dark`, `btn-outline-light` и своя `btn-accent`;
- `badge` — метки «Хит», «Новинка», «−20%», счётчик корзины;
- `alert` — сообщения пользователю (акция, информация о доставке, «Заказ отправлен»);
- `modal` — «Подписка на кофе» и «Купить в один клик»;
- `form-control`, `form-select`, `input-group`, `form-check` (чекбоксы, радиокнопки и переключатель `form-switch`);
- `accordion` — частые вопросы;
- `nav-tabs` (вкладки) — описание, характеристики и рецепт на странице товара;
- `toast` — уведомление «Добавлено в корзину»;
- `breadcrumb` — хлебные крошки;
- `list-group` — список в блоке «Ваш заказ»;
- `table` — таблица характеристик (`table-striped`, `table-hover`).

## Самостоятельные доработки

1. **Bootstrap подключён локально** — файлы лежат в `vendor/bootstrap/`, сайт работает без интернета.
2. **Дополнительная страница `contacts.html`** и выпадающее меню «Каталог» со ссылками на категории.
3. **Дополнительные компоненты Bootstrap:** carousel, accordion, вкладки, toast, dropdown, breadcrumb, list-group.
4. **Улучшенный каталог:** фильтр по категориям (кнопки «Все товары», «Кофе в зёрнах», «Для заваривания», «Аксессуары») со счётчиком товаров. Ссылки из меню, например `catalog.html#beans`, сразу открывают нужную категорию.
5. **Сценарий заказа:**
   - кнопка «В корзину» показывает уведомление и увеличивает счётчик на значке корзины;
   - ссылка «Оформить» в уведомлении открывает `order.html` с уже выбранным товаром;
   - на странице заказа при выборе товара, количества и доставки сразу пересчитывается итог;
   - формы проверяются стандартной валидацией Bootstrap: незаполненные поля подсвечиваются красным;
   - после отправки появляется зелёное сообщение `alert-success`.
6. **Блоки, которые «прилипают» при прокрутке (`position: sticky`):**
   - в блоке «От зерна до чашки» на главной карточка с текстом едет по фоновой фотографии, пока не закончится её блок;
   - на странице товара информация о товаре едет рядом с фотографиями (`sticky-lg-top`);
   - на странице заказа так же устроен блок «Ваш заказ».
7. **Анимации и эффекты:**
   - фон с параллаксом (`background-attachment: fixed`);
   - медленное приближение фото в карусели;
   - бегущая строка;
   - пульсирующий бейдж «Хит»;
   - приподнимание карточек и увеличение фото при наведении;
   - плавное появление блоков при прокрутке.
8. **Свой стиль в `custom.css`:**
   - кофейная палитра в CSS-переменных;
   - кнопки и формы перекрашены через переменные Bootstrap;
   - фоновые изображения шапок страниц;
   - своя кнопка `btn-accent`.
9. **Адаптивность:**
   - на телефонах и планшетах отключён фиксированный фон, на телефонах уменьшены отступы и заголовки;
   - стрелки карусели скрыты, слайды листаются свайпом;
   - на странице товара на телефоне одно большое фото и два маленьких в ряд (`col-6 col-lg-12`), чтобы цена и кнопка были ближе;
   - кнопка отправки формы растягивается на всю ширину.

## Как проверить проект

1. Откройте `index.html` в браузере или ссылку на GitHub Pages.
2. В DevTools включите мобильный режим (ширина 375 px): меню сворачивается в кнопку и раскрывается по нажатию, карточки встают в одну колонку.
3. Проверьте главную:
   - карусель листается сама и по стрелкам;
   - в блоке «От зерна до чашки» прокрутите страницу — карточка с текстом стоит на месте и едет по фоновой картинке;
   - кнопка «Оформить подписку» открывает модальное окно;
   - вопросы в блоке FAQ раскрываются.
4. В каталоге нажмите кнопки фильтра — количество товаров меняется. В меню «Каталог» выберите «Аксессуары» — откроется каталог с этой категорией.
5. Нажмите «В корзину» — появится уведомление внизу экрана, на значке корзины появится число. Ссылка «Оформить» откроет заказ с этим товаром.
6. На странице товара переключите вкладки «Описание», «Характеристики», «Как заварить» и откройте «Купить в один клик».
7. На странице заказа:
   - нажмите «Отправить заказ» с пустыми полями — поля подсветятся красным;
   - выберите товар и количество — справа пересчитается сумма;
   - заполните форму и отправьте — появится сообщение «Заказ отправлен!».
